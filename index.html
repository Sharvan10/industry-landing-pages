What every page includes

The fundamentals that make a landing page rank, load instantly and convert.

  • Speed first

    No frameworks or jQuery. A few KB of CSS and JS per page, lazy-loaded responsive images and deferred scripts.

  • Technical SEO

    Semantic HTML, logical headings, meta and Open Graph tags, canonical URLs and JSON-LD structured data.

  • Accessible by default

    Keyboard navigation, visible focus states, ARIA where it helps, AA colour contrast and reduced-motion support.

  • Mobile-first layouts

    Fluid type and CSS Grid layouts that look deliberate from 320px phones to wide desktop screens.

  • Conversion focus

    Clear primary CTAs, sticky navigation, trust signals and friendly, validated forms.

  • Easy deployment

    Static files that deploy anywhere. This portfolio ships to GitHub Pages automatically with GitHub Actions.
